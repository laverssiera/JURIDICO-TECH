# SCIENTIFIC IP RUNTIME

## Objetivo
Operar soberania intelectual cientifica do ecossistema: autoria, patentes, licenciamento, royalties e coautoria.

## Escopo
- Autoria e cadeia de descoberta
- Registro de patentes e prior art
- Licenciamento e royalties
- Transferencia tecnologica multiinstitucional

## APIs
- POST /science/authorship/register
- POST /science/authorship/validate
- POST /patents/register
- POST /patents/license

## Eventos
- science.authorship.registered
- patent.created
- patent.approved
- patent.licensed
